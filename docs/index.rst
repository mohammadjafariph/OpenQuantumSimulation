OpenQuantumSim
==============

OpenQuantumSim is a Python interface with a Julia backend for open quantum
system simulation. It is aimed at researchers who need Lindblad propagation,
Monte Carlo wave-function trajectories, collective-spin/Dicke models,
restartable sweeps, HDF5 outputs, and state diagnostics without leaving the
Python scientific stack.
