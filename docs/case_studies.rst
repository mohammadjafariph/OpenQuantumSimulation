Case Studies
============

A case study documents a real research calculation performed with
OpenQuantumSim: the model, why the package's features were needed, the
performance observed, and what the API made easy or painful. Case studies are
the best evidence that the package serves working researchers, and they feed
directly into the roadmap for the stable ``0.1.0`` release.

If you use OpenQuantumSim in your research, please open an issue or a pull
request adding a section below.

Template
--------

Each case study should include:

1. **Model and goal** - the physical system, the observable, and the research
   question (a few sentences; link the paper or preprint when available).
2. **Why OpenQuantumSim** - which features were load-bearing (solver choice,
   sweeps, HDF5 persistence, diagnostics, performance).
3. **Scale and performance** - Hilbert dimension, time grid, hardware,
   wall-clock time, and any comparison run.
4. **Reproduction** - a link to a repository, notebook, or a minimal script
   using only the public API.
5. **Friction** - anything you had to work around; this is roadmap input.
